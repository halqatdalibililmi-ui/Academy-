# Academic Auto System

نسخة أولية عملية لنظام أكاديمي عام متعدد المدارس، تعمل محليًا بدون خادم.

## المزايا
- إضافة عدد كبير من المدارس، مع الشعار والبيانات.
- إدارة الصفوف والطلاب والمواد.
- إدخال الدرجات مع حساب النسبة والتقدير والنجاح تلقائيًا.
- حساب ترتيب الطالب داخل الصف.
- مولد شهادة نتيجة ديناميكي يعتمد على البيانات.
- إنشاء سجل للاختبارات والامتحانات.
- نسخ احتياطي واستعادة JSON.
- تصميم RTL ومتجاوب.
- طباعة الشهادة أو حفظها PDF من نافذة الطباعة في المتصفح.

## التشغيل
افتح `index.html` في متصفح حديث.

## ملاحظة هندسية
هذه نسخة Front-end/Offline. للاستخدام التجاري متعدد المستخدمين والمدارس عبر الإنترنت يجب إضافة Backend وقاعدة بيانات ومصادقة وتخزين سحابي ورفع ملفات آمن وسجل تدقيق وصلاحيات.

## الخطوة التالية
يمكن نقل نفس النموذج إلى Firebase أو Supabase أو Backend مخصص، ثم إضافة حساب Super Admin، حساب المدرسة، المعلمين، الطلاب، التقارير المتقدمة، قوالب شهادات متعددة، QR للتحقق، واستيراد Excel/CSV.
